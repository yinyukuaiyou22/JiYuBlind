# 亲和性存活矩阵（原始实测）

环境：Windows 11 build 26200.9711，`diag/reset_probe.c` 自建窗口 + 自建抓屏（GDI BitBlt 屏幕 DC），
每步同时读 GetWindowDisplayAffinity 并抓屏取点。

| 步骤 | 亲和性 | 抓屏结果 |
|---|---|---|
| [0] 基线，未设置 | 0x00 | 能看到窗口 |
| [1] 设置 WDA_EXCLUDEFROMCAPTURE | 0x11 | 看不到窗口 |
| [2] SHOW -> HIDE -> SHOW | 0x11 | 看不到窗口 |
| [3a] 切全屏（改样式 + 铺满屏幕） | 0x11 | 看不到窗口 |
| [3b] 还原窗口尺寸 | 0x11 | 看不到窗口 |
| [4] 最小化 -> 还原 | 0x11 | 看不到窗口 |
| [5a] 分辨率 1920x1080 -> 1280x720 | 0x11 | 看不到窗口 |
| [5b] 分辨率还原 | 0x11 | 看不到窗口 |
| [6] 销毁后用同进程新 HWND 重建 | 0x00 | 能看到窗口 |
| [7a] 新窗口重新设置亲和性 | 0x11 | 看不到窗口 |
| [7b] 取消置顶（另起 topmost 窗口压在上面） | 0x11 | 看不到窗口 |

结论：同一 HWND 上的隐藏/显示、切全屏、最小化还原、改分辨率、置顶切换都不会清除亲和性；只有「窗口销毁后用新 HWND 重建」会归零。
